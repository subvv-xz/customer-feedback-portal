# Customer Feedback Portal

## Project Overview
The Customer Feedback Portal is a web-based system that allows customers to submit feedback about products or services. Authorized staff can view feedback and track its resolution.

## Objectives
- Allow customers to submit feedback easily.
- Validate required form fields.
- Display a confirmation after successful submission.
- Allow authorized staff to view submitted feedback.
- Track feedback status.

## User Roles
- **Customer:** Submits feedback.
- **Staff:** Views feedback and updates its status.
- **Admin:** Manages authorized staff access.

## Main Features
1. Submit customer feedback.
2. Validate feedback form fields.
3. Confirm successful submission.
4. Staff login.
5. View submitted feedback.
6. Update feedback status.
